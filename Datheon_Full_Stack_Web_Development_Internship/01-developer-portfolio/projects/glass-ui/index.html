Markup pattern

Wrap every control in a label so it keeps a visible name and a large tap target.

<label class="glass-field" for="f-name">Name
  <input class="glass-input" id="f-name">
</label>

<label class="glass-switch">
  <input type="checkbox" role="switch"><span></span>
  Send me a copy
</label>

Modal

Built on the native popover attribute. Esc, a click outside and keyboard focus all work without a script.

<button popovertarget="m1">Open</button>
<div id="m1" popover class="glass glass-modal">…</div>
