# Skycast: Live Weather

A weather app built with HTML, CSS and JavaScript that uses the OpenWeatherMap API.

**Features:** search any city or use the quick-pick buttons; current weather (temperature, humidity, wind, pressure, visibility, sunrise and sunset); 5-day forecast; loading spinner and error messages (for example, city not found); responsive layout; colour scene that changes with the weather; optional background photos in `images/`.

**Run it:** open `index.html` in a browser. Without an API key it shows demo data.

**Live weather:** get a free key at https://openweathermap.org/api and paste it into `API_KEY` at the top of `script.js`. Keep your real key out of public repositories.
