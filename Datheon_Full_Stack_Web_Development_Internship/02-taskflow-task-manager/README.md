# TaskFlow: Task Manager

A simple task manager built with HTML, CSS and JavaScript.

**Features:** add, edit and delete tasks; categories (Work, Personal, Study); due dates; search; drag-and-drop reordering; overdue highlighting; filters for All, Active and Completed with counts; tasks saved in `localStorage`.

**Run it:** open `index.html` in a browser. No installation is needed.

**Files:** `index.html` (structure), `style.css` (styling), `script.js` (logic and storage).
